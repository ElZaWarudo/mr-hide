# Mr Hide v0.1.0

Status: prepared on 2026-07-28; not yet tagged or published.

## Highlights

- Local privacy mediation for supported Codex Responses and Claude Code Messages traffic.
- English and Spanish PII detection plus technical-secret recognizers.
- Reversible conversation-scoped aliases backed by encrypted resumable vaults.
- Three explicit tool policies: `default`, `safe-tool-calls`, and `tool-compatibility`.
- Native launch and explicit resume support without persistent client-configuration changes.
- Bounded retention cleanup, bypass visibility, loopback-only proxying, and fail-closed privacy errors.

## Privacy boundary

Mr Hide protects supported conversational fields on `/v1/responses`, `/v1/messages`, and `/v1/messages/count_tokens`. Detection is best effort. Authentication, telemetry, updates, plugins, model discovery outside declared routes, binary or unknown protocol content, and non-inference traffic are outside the advertised protection boundary.

The default tool policy leaves provider-bound tool data unchanged and reports `tool-data-unprotected`. The safer tool modes may alter tool values and therefore require compatibility testing with the user's tools.
